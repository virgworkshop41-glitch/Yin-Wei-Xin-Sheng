穿越千年：從古人的信到今日公函

「公文是寫給『人』看的，先有心，後有格式——格式是盛載心意的器皿，不是目的。」

古代「書」體文歷經分化，屬於公文的「公牘」逐漸從個人書信中獨立；至宋代，「箚子」更體現了公文與書信功能的靈活轉換。本互動網站對照香港《政府公文寫作手冊》規範，助你寫出「有格式、有條理、有人情」的專業文字。

✍️ 講者開場手寫筆記：
  • 公文三大要素：格式、條理、人情。
  • 實務處理原則：匿名投訴信不用覆。
  • 字詞釋義：「箚」（音扎），原指寫在木／竹簡上的片段。

改寫與互評

熱身小測驗：古人說的，還是今人寫的？

點擊選項判斷出處，揭曉古今公文一脈相承的奧秘：

題目一
「取進止」
✓ 答案：古人說的（宋代奏箚結尾語）

意為請皇帝裁決行止，等於今日公函的「請核示」或「請批示」。

題目二
「如蒙光臨」
✓ 答案：今人寫的（《手冊》例2）

原句為「如蒙光臨，不勝感銘」，現代政府酬酢邀請信仍保留淺白文言的優雅韻味。

題目三
「辭達而已矣」
✓ 答案：古人說的（孔子《論語·衛靈公》）

蘇軾亦云「辭至於能達，則文不可勝用」。對應今日公函求準確達意、不求花巧。

四句古訓，串起整場講座

點擊卡片查看古訓出處與對現代公函寫作的具體啟示：

心

言為心聲

揚雄《法言·問神》

「言，心聲也；書，心畫也。聲畫形，君子小人見矣。」文字是內心的外現；函件的措辭、比例與溫度，就是發文者與機構的形象。

要

辭尚體要

《尚書·畢命》

「辭尚體要，不惟好異。」文章貴在合體、扣緊要點，不追求奇異辭藻，正是現代公文「簡明扼要」的源頭。

達

辭達而已矣

《論語·衛靈公》／蘇軾

達意不是粗糙，而是準確到位。蘇軾提出三重「了」：先了然於心（想清楚），再了然於口（說清楚），最後了然於手（寫清楚）。

誠

修辭立其誠

《周易·乾·文言》

《手冊·酬酢信》第2段指出「矯情固不可取，敷衍更欠真誠」。每封信都應有一句具體、真實、屬於這一封信的話。

一個「書」字，三副面相：公私隔閡，本是同根生

《說文解字》訓「書」為「著」（著於竹帛）；劉熙《釋名》：「書者，舒也，舒布其言，陳之簡牘」。

第一面相：載體與記錄

著於竹帛

最原始的意思是書寫、記錄，凡成篇文字皆可稱「書」，衍生出書籍、文書、書法、書信，涵蓋極廣。

第二面相：公牘之源

《尚書》：政事文告

《尚書》為上古政事文告彙編（典、謨、訓、誥、誓、命），屬君臣上下之間的政治性文字，是現代「公文」的遠祖。

第三面相：私信一脈

「中有尺素書」

漢樂府《飲馬長城窟行》「呼兒烹鯉魚，中有尺素書」。後世稱尺牘、書札、函、箋，重情感與人際交往。

時間軸：從先秦混同到宋代定型

先秦時期

公私混同，統稱為「書」，常以書信處理國家邦交（如《左傳》鄭子家〈與趙宣子書〉、子產寓書）。

兩漢時期

詔書、告書漸成體系。蔡邕《獨斷》分天子下行四品（策、制、詔、敕）與群臣上書四類（章、奏、表、駁）。

魏晉六朝

曹丕《典論·論文》提「奏議宜雅，書論宜理」；《文選》與《文心雕龍》將公文與私書分別編類，正式分途。

唐宋定型

唐有「狀」「牒」；宋代司馬光《書儀》定私信格式，「箚子」成為獨立且最常用的公文，公私體系完備。

✍️ 講者文化冷知識與手寫筆記：
  • 避諱制度：秦王嬴政名為「政」，故〈諫逐客書〉避諱寫作「秦王端」，「正月」亦讀作「端月」。唐代百姓若名「世民」（犯唐太宗諱），改為「系人」；太宗為示愛民如子，特批「二名不偏諱」，只改一字即可。
  • 紀念碑規矩：傳統紀念碑碑文不應用標點符號。
  • 訃告稱謂分寸：子為父喪自稱「不孝子×××」；若白頭人送黑頭人（父為子喪），則寫「孝男×××」。

名篇巡禮：古人如何「以書達意」？

寫作對象不同，語氣、結構與詳略各有講究。點擊不同名篇查看寫作結構與現代公文啟示：

子產寓書（《左傳·襄公二十四年》）

春秋·外交公函

「子為晉國，四鄰諸侯不聞令德，而聞重幣，僑也惑之。」

結構啟示：勸止晉國范宣子索取重幣。先指出現象 → 分析利害 → 提出根本（以德為基） → 勸止。今日向上級提不同意見，同樣應「先事實、再利害、後建議」，語氣有禮但立場清楚。

李斯〈諫逐客書〉（《史記》）

秦代·上書建議

「泰山不讓土壤，故能成其大……此所謂藉寇兵而齎盜糧者也。」

結構啟示：先列歷史事實（四君用客而強） → 對比現實 → 指出後果。向決策者提建議時，「事實＋比較＋後果」遠比單純表態有力；比喻宜精不宜多。（筆記：李斯本人亦為楚國人）

李密《陳情表》＆ 魏徵《諫太宗十思疏》

上行奏表疏

《陳情表》：先陳事實（孤弱） → 再講理由（侍奉祖母） → 最後提請求（暫緩赴任），與今日公函「背景 → 理由 → 請求」完全同構。
《十思疏》：逐條列出「十思」，論點可數，是公函「分條說明」的古代範本。

丘遲〈與陳伯之書〉＆ 韓愈「去陳言」

勸喻與文風

勸降書手法：先肯定才華 → 再析利害 → 以「暮春三月，江南草長」動之以故國之情 → 曉以大義，一信勝千軍。
韓愈提醒：「惟陳言之務去」「文從字順各識職」，公文切忌堆砌空洞四字詞。

✍️ 手寫批註：丘遲書中「群鶯亂飛」之「鶯」分雌雄（如同「鳳凰」，鳳為雄、凰為雌）；寫公文「內容最重要」。另旁註：「AI draft信：偏向長（因不想漏東西）」，須用韓愈「去陳言」精神精煉之。

宋代「箚子」登場：公私兼備、上下通行的新文書

明代徐師曾《文體明辨序說》指宋人「箚子之用居多」。「箚」是「札」的異體（小木片），「子」表小，即小巧簡便的文書，取代繁複的表、狀。

一、公文箚子（處理公事）

  • 上行（奏箚、牒箚）：奏箚向皇帝奏事（有身分限制）；牒箚向長官或上級機構匯報公務，低微小官亦可用。結構特點：「前不具官」「不用右」，事末云「取進止」（仁宗時定型，即今日「請批示」）。
  • 下行（御筆箚子、省箚、帥箚）：皇帝或中書省、樞密院下達指令。如元豐二年〈中書箚子〉：交代事由 → 奉聖旨指令 → 分派責任 → 收結「箚付丹州。準此。」（即今日「謹按此辦理」）。

二、私箚子與書儀（交際往來）

  • 官場交際：南宋紹興年間起，箚子取代繁冗的「疊幅小簡」（3至13幅），與「啟」合稱「雙書」，用於賀、謝、干求（洪邁《容齋四筆》曾警示官員勿請人代筆應酬）。
  • 朋友書信與《書儀》：司馬光《書儀》規範稱謂、敬辭與書寫位置，使私信有定式，公文得以獨立發展。

宋代四大經典案例拆解

1. 蘇軾五步奏箚（進呈魏徵《群書治要》）

①自謙入題（說明身分來意） → ②比喻說理（醫者用藥） → ③事實為據（引魏徵書） → ④提出請求（繕寫進呈） → ⑤套語收結（「取進止」）。

✍️ 筆記：魏徵《群書治要》輯錄群書重點給唐太宗，但故意不收錄與「孝」有關的部分（避諱玄武門之變）。
2. 王安石〈答司馬諫議書〉四步拆解批評

面對司馬光勸罷新法，王安石展現高超回信藝術：①承接來函（「昨日蒙教」＝來函收悉） → ②概括論點（歸納為侵官、生事、征利、拒諫四項） → ③以「名實」逐點辯駁 → ④誠意作結，不傷和氣。

3. 天價書信：曾鞏〈局事帖〉（124字）

訴說外任十二年苦悶並祝友人「前即召擢」。1996年紐約452萬人民幣成交 → 2009年北京1.0864億 → 2016年嘉德2.07億元成交（平均每字167萬）。示範私信「有定式、有心聲」。

✍️ 講者幽默眉批：曾鞏是歐陽修學生，其書法被調侃「拉低唐宋八大家的GPA」（並註：《蘇東坡文集》值得看☆）。
4. 歐陽修〈與高司諫書〉＆ 手寫回信規矩

歐陽修責問高若訥對范仲淹被貶保持緘默（「是不復知人間有羞恥事也」），示範公函遇爭議時須「據事而論，避免人身攻擊」。

✍️ 筆記：收到手寫書信，覆函亦應用相應格式形式（講者幽默旁註：「血書？」）。另註：最忌信的成份殘缺；中文無「您們」一詞。

現代公函六項基本功與稱呼學問

1. 性質與用途

政府為公事發出的書信：與市民、公私營機構聯絡、內部通訊及與內地單位公務往來。

2. 迅速回應（10日原則）

收到來信須迅速回覆；如未能在10個工作日內給予具體答覆，須先發出「簡覆」告知進度。

3. 語文規定（《總務規例》第529條）

中文來信一律以中文回覆（無論直接用中文撰寫，或先以英文起草再翻譯）。

4. 書寫方向

現時政府中文公函一般用橫式（內文含英文或阿拉伯數字時較便）；直式多用於酬酢書函。

5. 白話為主，酌用淺白文言

一般以白話文撰寫，可因場合酌情採用淺白文言（如「承蒙」「謹此致謝」），通篇風格須一致。

6. 稱謂「不卑不亢」

不用「鄙人」「敝署」；不提行、不離格；已婚女性全稱夫姓先行（陳李議員），單提姓氏用本姓（黃議員）。

✍️ 講者實務手寫批註（稱謂、格式與AI工具）：
  • 稱謂順序禁忌：應寫「×××校長」，切勿寫「×校長×××先生／教授」（職銜與先生／教授不可疊加倒置）。
  • 英文署名中文來信：若對方來信以中文寫但署名英文（如 Chen），回函可禮貌稱呼「Chen 先生／女士」或「執事先生」。
  • 空格與下款位置：格式中隔一格必須為全形空格；正式公函下款靠右，電郵則下款靠左。
  • AI 輔助寫作實測比較：講者實測指出「Deepseek 中文較好；Gemini 英文較好（中文略帶內地風格）」，使用時須按香港公文語境潤飾。

公函「體檢表」：八大毛病自查

發函前花一分鐘對照這八項，可避免大半常見錯誤：

1. 缺事由：首句必須交代來函日期與事由。
2. 結論後置：先給答案（同意/拒絕），再說細節。
3. 一句多事：拆開超過60字長句，一句一意。
4. 套話堆砌：刪去「茲因…爰特…」，改為淺白具體。
5. 稱謂不一：切忌前稱「貴署」、後稱「你們」。
6. 資料不一：核對日期、數字、人名職銜前後一致。
7. 語氣失當：不辯解、不推卸，視對象調整溫度。
8. 過度承諾：避免「一定」「保證」，改用「會盡力」「預計」。

壞消息與投訴回覆「四步走」心法

回覆投訴不是辯護，是「讓人明白，並讓人安心」：
① 說清事實（先接住：「來函收悉，我們十分重視」） → ② 說明原因（客觀依據，不找藉口） → ③ 誠懇致歉／補救措施 → ④ 留下聯絡出路。

《手冊》例2：邀請出席周年晚宴

邀請信六個動作

① 交代時間地點（「本隊謹定於…舉行七十周年晚宴」）
② 說明規格（「司司長朱大衛勳賢將蒞臨主禮」）
③ 感謝並建立關係（多年來得到貴會鼎力支持…）
④ 正式邀請（「誠邀出席，共敘言歡，藉增榮寵」）
⑤ 謙辭（「如蒙光臨，不勝感銘」）
⑥ 方便回覆（「添附回條，敬候示覆」）

《手冊》例3：答應出席並題辭

爽快赴會＋具體行動

① 確認來函日期（「二零XX年三月一日來函敬悉」）
② 明確答應（「深感榮幸，屆時定當依約赴會，參與其盛」）
③ 附送題辭（「謹呈拙筆，聊申賀忱」）
④ 緊扣機構祝願（「謹祝貴會信昭基固，事業昌隆。」）

《手冊》例18：婉拒出席喜宴

拒絕也有溫度

① 先謝（「欣接華柬，承邀出席令媛于歸之喜…不勝感銘」）
② 簡短原因＋致歉（「惜當日公務安排緊密，未能趨賀，務祈涵諒」）
③ 以祝福替代出席（「謹此遙祝一對新人舉案齊眉，永結同心」）
④ 尊重心意（如主人家意捐助護老服務，收束「肅此奉賀，兼候台安。」）

《手冊》例20：謝贈書刊

讚賞要說到點子上

① 第一句點題：「承蒙惠贈書法作品集，隆情厚意，不勝感銘。」
② 看見對方心思：「博士身居要職，事務繁忙，仍抽空揮毫臨池…」
③ 適度肯定成果：「今將大作結集成書，以饗同道，誠為美事。」
④ 收束：「贈書雅意，專函敬謝，順頌台祺。」

《手冊》例30：謝款待

短信見真情（致謝三步曲）

① 言明所謝何事：「荷蒙邀約，今日與你共進午膳」（用「今日」顯及時）。
② 強調良好效果（兩種感受）：「美饌佳餚，令人開懷愉悅；得聆高見，更是受益不淺。」
③ 收束：「仰蒙盛意，銘感於心。謹修寸柬，以申謝忱。」（自稱「寸柬」，信短情真）。

《手冊》例45：賀獲授勳銜

誇得準，也誇得穩

① 點明喜事：「欣悉你獲頒授金紫荊星章，捷報傳來，不勝雀躍。」
② 以事實肯定貢獻：「會長熱心公益，領導香港聯合會逾十載，竭力推陳致新，扶老護幼。」
③ 適度評價：「洵屬實至名歸」（切忌用「全港最偉大」「前無古人」等浮誇詞）。
④ 寄語祝福：「並祝身心康泰，諸事順遂。」

《手冊》例49：賀當選政黨主席

政治人物祝賀的分寸感

① 開門見山：「欣悉你當選△△黨來屆主席，特函致賀。」
② 回溯資歷與社會評價：「自貴黨創立之初，你已是骨幹要員…高才大德，眾皆稱道，今榮膺主席，深孚眾望。」（借「眾望」立論，不代全港表態）。
③ 以公共利益寄語：「冀盼貴黨與政府保持緊密合作，以民為先，共建繁榮。」

《手冊》例60：慰問殉職同事家屬

樸實見真情（忌浮誇、忌敷衍）

① 直接表達哀慟：「痛悉尊夫昨晚執勤時不幸殉職，本處同人深感哀慟。」
② 概述生前貢獻：「唐先生在本處任職多年，能幹盡責，表現傑出，深受同袍敬重。」
③ 真誠克制：「永訣之痛，非言語所能慰解，尚望節哀順變，保重身體為要。」
④ 實質支援：「如需協助，請隨時告知，我們定當略盡綿力。」

✍️ 手寫筆記：慰問信「不要太浮誇」（如「如五雷轟頂、痛不欲生」令人不安；只寫「節哀。」則太敷衍）。
《手冊》例76：災情慰問

代表政府發聲

① 交代災情：「驚悉……本月十日發生強烈地震，多處塌方，傷亡枕藉。」
② 同理心基礎：「內地和香港血脈相連，同胞遭逢厄困，切膚之痛，感同身受。」
③ 明確代表身分：「謹代表香港特別行政區政府致以深切哀悼與慰問。」
④ 循序祝願：救災順利 → 受困者早日脫險 → 重建家園復見。

✍️ 手寫筆記：例76體現「中港連繫」；避開「天災無情，人間有愛」等空洞口號式套話。

酬酢信詞庫（點擊即可複製）

詞庫是「參考」不是「模板」：先想清要說什麼，再選詞。

酬酢信「六大陷阱」避坑指南

  • 1. 套用範本，不看對象：安好語須適人適事（如對長輩、商界、同僚各有不同）。
  • 2. 過譽而流於誇飾：評價必須合度，否則顯得虛假。
  • 3. 敷衍了事：「矯情固不可取，敷衍更欠真誠」。
  • 4. 文白不協調：白話正文後硬配艱深文言安好語，顯得突兀。
  • 5. 由他人「代行」發信：酬酢信宜親自簽發或回覆，不宜以「代行人」名義發出。
  • 6. 格式混亂：橫式信末請候語與安好語之間無須留空，句末加句號或嘆號（上款不加敬啟者）。

互動工作坊：三個情境實戰練習

先在草稿區獨立撰寫，完成後點擊「顯示參考示例與逐項拆解」進行對照：

情境與原稿（故意寫壞版）

情境：某社區團體（十月十日來函）申請於十一月二十日借用本署多用途室，本署原則上同意，但需待消防安排確認（十一月十五日前通知）。

問題原稿：「關於你們上次問的場地的事，我們內部商量了一下，覺得可能可以，不過還要看看情況，等有結果再通知你們。」

任務：按「緣由、結論、細節、結語」四步重寫（約80-100字）。

參考改寫示例
「貴會於十月十日來函，申請於十一月二十日借用本署多用途室，本署已收悉。經審核，本署原則上同意申請，惟須待消防安排確認後方可作實。本署將於十一月十五日或以前以書面通知貴會。如有查詢，請聯絡本署行政組陳小姐（電話：2xxx xxxx）。特此函覆。」
  • ✅ 緣由：補齊「十月十日來函」與事由。
  • ✅ 結論：「原則上同意」取代「可能可以」，並清楚列明條件。
  • ✅ 細節：「十一月十五日或以前」取代「等有結果」。
  • ✅ 結語：提供具體聯絡人與電話，以「特此函覆」收束。
情境與任務

情境：本署於十一月八日舉辦「長者數碼學習日」，約二百位長者參加。某區社區中心免費借出場地並安排十位義工協助。活動後不少長者首次學會用智能手機預約門診。請以署長名義寫給中心陳主任一封致謝信（約150字）。

要點：言明所謝何事 ＋ 強調良好效果（有數字有畫面） ＋ 寄望日後。

參考示例（橫式、白話）
陳主任：
　　十一月八日的「長者數碼學習日」，承蒙貴中心免費借出場地，並安排十位義工協助，約二百位長者得以參加，謹此衷心致謝。
　　當日不少長者首次學會用智能手機預約門診，義工耐心講解，場面溫馨感人。期望日後再有機會與貴中心合作。特此致謝，並祝工作順利，身體健康。
  • ✅ 最具體的一句：「首次學會用智能手機預約門診，義工耐心講解」——有畫面、有溫度，遠勝空喊「活動圓滿成功」。
  • ✅ 安好語得體：對象是社區工作者，用平實白話「祝工作順利，身體健康」。
情境與任務

情境：某中學來函，邀請署長出席五十周年校慶晚宴並致辭。當晚署長已有預先安排的公務，無法出席。請以署長名義寫給李校長一封回覆信（約120字）。

要點：先感謝 ＋ 解釋原因並道歉 ＋ 肯定學校成就與祝願。

參考示例（橫式、白話）
李校長：
貴校五十周年校慶晚宴
　　承蒙邀請本人出席貴校五十周年校慶晚宴並致辭，盛情厚意，謹致謝忱。
　　惟當晚本人已有預先安排的公務，未能分身，不能出席，深感抱歉。
　　貴校五十載樹人，培育英才，貢獻良多。謹祝校慶活動圓滿成功，校務蒸蒸日上。
  • ✅ 先謝後辭：「不能出席」要說清楚，婉拒含糊只會令對方無所適從。
  • ✅ 肯定與祝願：「五十載樹人，培育英才」評價合度不過譽。

互評表：五問檢查一封信

點擊勾選完成自我檢查（先圈最好的一句，再改最需改善的一處）：

明天上班就用：五個行動

  1. 1 先寫結論：下次回函，先用一句話寫結果，再補充細節與依據。
  2. 2 一句一意：把超過六十字的長句拆開；刪去「進行」「作出」等空洞動詞。
  3. 3 稱謂配對象：重看稱謂、請候語、安好語是否切合身分，文白前後協調。
  4. 4 酬酢寫具體：每封酬酢信寫出一句具體的話：誰做了什麼、帶來什麼成果。
  5. 5 定稿前朗讀：朗讀一遍，再用互評表自查；拗口、含糊之處，多半有問題。
